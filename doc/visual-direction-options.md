# 《远方来信》视觉方向候选

## A. 风暴后的公路电影（推荐）

自然光、潮湿道路、旧车站、远山、车窗、渡船和人在真实环境中的细微表情。UI 像旅行者使用过的路册：温暖浅灰纸、深墨、风暴蓝、路标橙和少量邮戳红。

优势：最通俗，最容易让玩家相信远方真实存在；人物与环境都能成为主角；不依赖复杂奇幻设定。

风险：如果镜头导演不够强，会退化成普通旅游插画。

## B. 活地图与路线档案

画面仍是完整场景，但地图、天气、邮戳和路线证据具有更强的信息设计感。UI 更接近现代交通档案与纸质地形图，强调距离、海拔、路况和发现记录。

优势：探索规则最清楚，地图层容易形成辨识度。

风险：信息过多会让游戏像工具；必须让场景和人物先于图表。

## C. 风暴边缘的抒情现实

更强调天气、光线和空旷尺度：远处的雨幕、风吹过草原、湖面低云、雪线和灯塔。UI 更克制，使用雾白、深青、暗黄灯光与低饱和红。

优势：情绪最强，适合第一人称远望和大世界发现。

风险：若所有画面都空旷忧郁，人物生活会变薄，区域之间也可能显得相似。

## 推荐组合

以 A 为主体、吸收 B 的地图可读性和 C 的天气尺度。不要把三套材质混合：场景采用公路电影，地图采用交通档案，天气只作为区域光线与构图规则。
