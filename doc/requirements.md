# 《远方来信 / Letters from Afar》需求文档

## 1. Overview

### 游戏定位

《远方来信》是一款图文时间线优先、影像辅助的异步多人共享世界 RPG。玩家从风暴后的海边小镇出发，携带一封由“三年后的自己”寄出的信，自由穿越一片重新连通中的大陆，寻找信中提到的白塔与那些从未收到回信的人。

- 单次体验：开放式探索为主、短任务为辅的混合体验；一次访问通常完成一段路程、一个现场事件或一次人物交往。
- 期望投入：单次约 8–15 分钟，也允许完成一个选择后自然暂停。
- 跨次连续性：长期个人旅程＋持续变化的异步共享世界。
- 持久状态：位置、已知地图、开放路线、信件线索、人物关系、同行者、行囊、精力、旅费、个人任务、共享事件游标与未处理回执。
- 停止点：抵达安全地点、解决现场事件、完成一段路线或明确选择扎营后均可安全退出。
- 回访理由：继续前往远方、追查未来来信、与已认识的人重逢、探索新开放路线，以及查看其他玩家对道路和聚落造成的变化。

一句话核心循环：**听见远方的传闻 → 选择目的地和路线 → 处理旅途中的具体事件 → 抵达并留下改变 → 决定继续、转向或停留。**

### 玩家承诺

- 发现页：一封不可能存在的来信，承诺一场可以自己决定方向的大陆旅行。
- 首个有效动作：首屏先用一句话说明玩家是刚登记的临时邮路员，明早要替旧邮局把积压信件送往内陆；风暴封路使玩家今晚留下抢救受潮信件。随后才出现突然落下的干信封，艾达确认门外无人、信封写着玩家名字且没有投递记录，因此由即将接手邮路的玩家决定如何检查。第一次行动才发现“三年后的日期”，第二次行动才得到盐沼旧堤与涨潮时限。北渡口和共享路线证据留给后续情节，不在开场倾倒。
- 第一段体验：抵达第一个新地点、认识一名角色、处理一件完整事件，并看到一条真实的其他玩家痕迹。
- 前 10 分钟：理解目的地、路线与途中事件的区别；知道未来来信是长线目标，但不追主线也可以获得完整体验。
- 单次结束：至少有一项可见变化被保存，例如抵达、发现、关系变化、路线改善或信件线索。
- 长期体验：个人地图逐步展开，人物会移动，公共道路会变化，未来来信的含义因玩家做过的选择而改变。

### 前五分钟吸引力合同

- `0–20` 秒：知道自己是明早接手积压邮件的临时邮路员，并在封路的夜晚亲眼看见一封写着自己名字的干信封落进湿地板；首屏不解释未来日期、旧邮戳、路线历史或共享系统。
- `20–45` 秒：在“检查邮戳日期 / 请艾达检查投信口”中完成第一个判断，得到一个短事实链，并发现信封日期来自三年后。
- `45–120` 秒：通过检查档案柜或只读信件第一行，得到盐沼旧堤与涨潮时限，再亲手决定是否立即出发；每个节拍只新增一组可使用信息。
- `2–5` 分钟：完成第一次可见回报，至少包含一项：发现新地点、解决一个短现场、获得明确报酬、接过一封接力信或使用其他玩家留下的有效设施。
- 第一次乐趣必须来自谜团、路线选择、人物反应和世界变化；不使用签到、抽奖、连续奖励或无来源货币刺激代替核心体验。
- 任一路径若在 5 分钟内仍只有阅读、泛化观察或准备菜单，切片验收失败。

### 世界规模

世界包含 7 个稳定大区域、30 个首发固定地点与可持久化的沿途生成地点。固定地点承载主线、重要人物和公共工程；生成地点只补充某条路线的局部发现，第一次生成后获得稳定 ID、所属路线和世界事实，之后不得随意改名或漂移到其他区域。

当前已实现两批世界扩展：24 个稳定地图节点、10 名稳定角色，以及四条从首发切片继续深入的完整链路——“盐沼旧堤 → 旧公路旅舍 → 横风农场”“北渡口 → 杉湖镇 → 湖上驿站”“横风农场 → 月台城 → 圆顶机车库 → 被埋支线”和“湖上驿站 → 干河驿站 → 岩洞村 → 峡谷公路 → 子午观测站”。白脊山脉与远岸群岛仍属于已锁定的后续规划，未实现地点和人物不得在关系面板、快捷选项或存档中预载。

七个区域为：

1. 雨港海岸：起点、旧邮局、盐沼、渡口与风暴遗迹。
2. 长风草原：农场、移动集市、废弃公路与候鸟湿地。
3. 湖林地带：林中聚落、湖上驿站、木桥与旧疗养院。
4. 断轨盆地：铁路城、维修厂、矿镇与被沙掩住的支线。
5. 赤土高原：峡谷公路、岩洞村、观测站与季节河流。
6. 白脊山脉：雪线驿站、隧道、索桥与风暴观测塔。
7. 远岸群岛：大陆尽头、灯塔群、潮汐邮局与最终白塔。

## 2. Visual Design

视觉目标是“旅行者亲历的一本活地图”，而不是地图菜单或卡片游戏。主要场景使用完整电影画面，地图、路线和信件只作为操作层，不把世界变成纸张拼贴。

- 移动端主要结构：简洁状态栏 → 可持续回读的累积正文 → 与当前段落绑定的场景图片 → 当前有效行动轨道。
- 地图是可进入的独立层，显示已知区域、具体路线、天气、距离、开放条件和其他玩家痕迹；现场事件未结束时地图保持可查看但不直接跳走。
- 普通场景镜头采用均衡导演：连续 20 个普通场景约 10 个第一人称、10 个观察者/第三人称；重要对话优先第一人称看向对方，新地点首次抵达优先广角观察镜头。
- 第一人称画面禁止显示玩家的脸、头、肩背、剪影或镜中倒影，也不得为了“像第一人称”凭空生成手。
- 场景图必须明确当前地点、天气、时间和正在发生的事件；禁止旧地点图片继续附着到新地点。
- 地图区分“从未听说”“听说但未到达”“已到达”“暂时受阻”“公共道路改善”五种状态。
- 所有功能图标使用统一 SVG 线性体系，不使用 Emoji。

完整色彩、字体、材质、图标、动效和出图提示在方向确认后写入 `doc/visual.md`。

## 3. Game Mechanics

### 3.1 核心动词

- 观察：读取眼前环境、人物行为和路线证据。
- 交谈：获得名字、意图、关系、任务与矛盾信息。
- 行动：修理、帮助、调查、交换、躲避、保护或承担风险。
- 旅行：选择明确目的地和一条当前成立的路线。
- 记录：把地点、线索、路线和已证实事实写入个人路册。
- 留下：在授权范围内留下路标、营地、物资或公共工程贡献。
- 休息：在具体环境中恢复精力并推进明确时间。

### 3.2 三层循环

现场循环：看见具体局面 → 选择处理方式 → 得到可见后果 → 继续处理或结束现场。

旅程循环：选目的地 → 比较 2–5 条当前成立的路线 → 准备 → 经历 1–3 个路线事件 → 抵达新地点。

长期循环：展开地图 → 结识与重逢人物 → 收集未来来信线索 → 改变公共道路 → 决定最终如何回应三年后的自己。

### 3.3 数值与资源

#### 精力 `0–100`

- 普通旅行消耗 6–14 点；高强度行动消耗 8–18 点。
- 明确选择“短休”恢复 16–24 点并推进 45–90 分钟；安全过夜恢复到至少 70，通常增加 35–60 点并推进至下一自然时段。
- 休息不会因为隐藏的通用成本产生净减少；若环境危险导致无法充分恢复，选项出现前必须明确说明预计结果。
- 精力为 0 时不允许继续高强度行动，进入确定性的撤回、求助或原地恢复流程；不会产生无选项死局。

#### 旅费 `0–99`

- 住宿、交通、食物和购买只能由玩家明确选择后扣除。
- 文案中的“获得报酬、收到钱、支付费用”必须在同一权威回合产生对应数值事务；承诺未来付款不提前入账。
- 金额、物品和服务必须在选项中清楚写明；模型不能自行替玩家花钱。

#### 线索 `0–12`

- 只在获得可验证的未来来信证据时增加，不作为普通探索奖励泛发。
- 线索不会被消费。达到 4、8、12 时分别开放新的信件层、白塔区域与最终回应选择。
- 玩家即使不追线索，也能探索所有非终局地区并完成地方故事。

#### 行囊

- 物品具有稳定 ID、来源、数量、持有者与用途。
- 获得、花费、转交、遗失和公共领取必须通过结构化事务；正文不得与权威库存冲突。
- 公共物资进入个人行囊时使用唯一回执，个人存档回读成功后才确认领取。

### 3.4 目的地、路线与现场事件

- 目的地回答“最终要去哪里”；路线回答“怎样去”；现场行动回答“眼前先做什么”。三者不得混在同一组选项里。
- 现场存在未解决的袭击、救援、审问、谈判、修理或即时危险时，进入 `active_incident`。系统推荐必须优先处理、拖延、求助或明确撤离该事件，不能突然切换到工作、吃饭、泛化观察或远途旅行。
- 玩家可以查看地图，但只有选择“撤离当前事件”并承担可见后果后才真正离开。
- 路线开始后保留 `journey_id`、起点、目的地、路线、阶段和未解决事件。普通休息不会清空旅程。
- 地点更新、正文、选项和图片必须作为一个场景原子提交；任一部分不一致则整回合不写入存档。
- 一个选项只有在目标存在、前提成立、成本可支付、结果可以由规则继续承接时才显示。没有必要凑满三个；允许 1–5 个高质量选项。
- 不成立的用户自由输入不会被伪装成成功。系统应说明具体阻碍，并提供保持原意的可行替代；技术错误则保留原意并允许同 action ID 重试。

### 3.5 内容结构

- 主线由 5 个章节门槛构成，不要求固定地区顺序：来信、失联者、旧邮路、白塔来源、最终回应。
- 每个大区域至少包含 2 条人物线、2 类地方矛盾、2 类探索发现、1 个可重复但会变化的生活活动和 1 个公共工程。
- 首发预设 14 名稳定角色；未来角色在可见登场前隐藏。首次登场遵循“外形/动作 → 名字来源 → 当前意图 → 允许互动”。
- 3 名可长期同行者的能力和价值观不同；加入、离开、敌对、失踪和重逢都必须在可见正文中发生并持久化。
- 动态事件按区域、路线、天气、时间、同行者、当前事件和近期历史过滤；同一事件模板不得在 8 个成功回合内重复。

### 3.6 异步共享世界

个人主线、私人关系、秘密、个人行囊和结局由个人存档拥有。共享世界只能提供环境事实与可选机会，不能直接替玩家完成私人任务。

共享层包含：

1. 旅人痕迹：路况警告、已验证路线、临时营地和系统约束的短留言，48–168 小时后淡出。
2. 接力信件：一名玩家把系统生成并审查过的封缄信带到下一地区，另一名玩家可以继续传递；每次交接拥有稳定信件 ID、持有者和回执。
3. 公共道路：玩家贡献修理、引路或补给，使一条路线在当前周期更安全、更快或出现新停靠点。
4. 季节工程：每 7 天结算一次区域工程；按不同贡献者计数，同一玩家不能刷满。
5. 永久地标：只由白名单规则在满足人数、贡献和审核条件后产生，例如恢复的桥、邮站或避难屋。

每个共享写入使用稳定 `action_id`、预期版本、规则版本和服务端身份。重复提交返回首次结果；版本冲突刷新后重新验证原意，最多重试三次。响应丢失视为未知结果，按同一 action ID 和 cursor 对账，绝不生成第二笔事务。

其他玩家造成旧选项失效时，必须显示具体世界变化和新的可行选择，不能回退到泛化“查看这里能做什么”。在没有其他玩家活动时，个人主线和所有结局仍可完整进行。

### 3.7 推荐选项合同

- 第一优先：正在发生且尚未解决的现场事件。
- 第二优先：玩家刚刚明确承诺的任务或旅程。
- 第三优先：当前地点中的具体人物、物件和可观察变化。
- 第四优先：与已知目的地相关的路线选择。
- 最后兜底：描述当前地点中的具体可见对象；只有确实没有更具体事实时才使用“观察周围的新变化”。
- 不得推荐刚完成的动作、已失败且前提未改变的动作、未知人物/地点、与当前位置冲突的活动或会清空活跃故事的通用生活选项。
- 每个推荐必须能说明：依据哪条当前事实、预期改变什么状态、失败后如何继续。

### 3.8 生成式地点

- 用户可以提出前往未预设的地点。系统先把意图归入当前区域与可达路线，并判断它是传闻、沿途地点还是新聚落。
- 成立时生成稳定 `place_id`、名称、区域、父路线、首次发现事实、可返回锚点和视觉标签，然后原子写入个人地图；公共化需要额外审核与多人规则，不能由一名玩家自由输入直接改变所有人的世界。
- 不成立时说明现实阻碍，例如距离、缺少渡船或当前事件未解决，并给出保持目标的准备行动。

### 3.9 难度、失败与恢复

- 挑战主要测试信息判断、路线规划、资源安排和社会判断，不依赖快速反应。
- 检定失败改变代价、时间、关系、路线或信息质量，但保留可继续的下一步。
- 不允许失败后返回完全相同的选项与完全相同的世界状态再次扣除资源。
- 危险连续 2–4 回合后必须升级、转向或结束；不能无限循环。
- 玩家随时可以在安全地点暂停；离线不会损失个人物品或私人关系。

### 3.10 首发内容容量

- 7 个大区域，30 个固定地点，18 条固定区域路线。
- 14 名预设角色，其中 3 名可长期同行。
- 42 个区域事件、28 个路线事件、14 个重要人物事件、12 个未来来信线索事件。
- 7 个公共工程、21 类旅人痕迹、9 类接力信件目标。
- 至少 6 种结局组合，由未来来信回应、同行关系、恢复道路、帮助失联者和是否保留白塔机制共同决定。

## 4. Controls

- 点击/轻触当前选项：提交一次行动并立即显示已接收反馈；网络重试不生成新的 action ID。
- 横向滑动行动轨道：浏览 1–5 个有效行动；滚动时不触发选择，选项使用 `onClick`。
- 点击地图按钮：查看当前地点、已知目的地、路线和共享道路状态；现场事件未结束时仍可查看但不无代价跳转。
- 点击精力、旅费、线索：查看简短说明、获得与消耗规则及当前影响。
- 点击关系/路册按钮：查看已登场人物、同行者、已知地点、信件与路线记录。
- 自由输入：表达玩家意图；提交前保留原文，结果必须说明原意是否成立及为什么。
- 键盘：数字键选择当前可见选项；输入框聚焦时数字键只输入文字，不触发行动。

## 5. Win / Lose Conditions

游戏没有传统 Game Over。

- 章节完成：找到足够证据并推进未来来信的一个层级。
- 地方完成：解决或明确放弃一个地区矛盾，世界保留结果。
- 部分成功：达成目标但付出时间、关系、物资或路线代价。
- 失败：行动没有达到目标并产生可见后果，但至少保留撤回、求助、换方法或处理后果的路径。
- 精力归零：进入恢复事件，不允许继续高强度行动，也不清空旅程。
- 最终完成：抵达白塔并决定给过去寄出什么、是否保留逆时邮路，以及未来旅人还能共享什么。
- 继续：结局后仍可留在已改变的大陆旅行、完成地方故事与参与公共道路；结局不会把存档替换成空白周目。

## 6. Sound Effects

- 低干扰阅读门禁：普通选择最多播放一次轻确认；普通正文到达、图片完成和常规精力/信迹变化保持静音。只有检定、旅费结算、稀有物、关系转折、危险阶段、地点抵达或章节节点等独立持久后果，才可在同回合稍后追加一次语义提示。合成 SFX 总线额外乘 `0.52`，瞬态声部最多 6 个，录制音效最多 2 个，`180 ms` 内的成组触发合并。

- 主题音乐：一段 90 秒、约 64 BPM 的无歌词旅行主题，以低调的木吉他、钢琴、提琴与远处手风琴构成；自然收尾后留 5 秒安静，再重新进入，不伪装成无缝循环。
