# Letters from Afar / 远方来信

《远方来信》是一个双语、持续存档的异步多人共享世界文字 RPG 实验。玩家从风暴后的漂港出发，沿邮路寻找寄自未来的信；不同玩家会在同一张道路网络上留下临时路迹、改善路线并接力递送信件，但人物关系、数值和私人剧情仍归各自存档。

当前版本包含通过验收的垂直切片与第一批世界扩展，共有 15 个稳定地图节点、6 名稳定角色，以及草原、湖林两条可完整走通的区域门。开场在 45 秒内提供第一个有后果的选择，并在五分钟内给出可见回报。运行时图片由 AlterU Media Service 生成，不使用 Imagine。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 验收

```bash
npm test
```

统一回归共 26 组测试，覆盖母引擎协议与安全门禁、开场三条吸引路径、两条首发路线、草原与湖林扩展、未来角色可见登场、共享路迹、路线贡献、接力信领取与交付、幂等提交、冲突恢复，以及 16,000 步长程模拟。

项目文档位于 `doc/requirements.md`、`doc/visual.md` 与 `doc/technical.md`。
